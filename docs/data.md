# Данные для повторения решения

Папка автора: [Google Drive](https://drive.google.com/drive/folders/1G5tqSNlCG89dKWfuCzvM4TkXhgPvkCPc?usp=sharing).
Автор добавляет ZIP с сохранёнными данными. На момент обновления документации
имя, размер и контрольная сумма архива ещё не зафиксированы; загрузка и доступ
по ссылке не подтверждены. Ссылка на папку сама по себе не гарантирует доступ.

## Для получения submission

Обучение повторять не нужно. Все три файла `artifacts/model/` уже в Git.
Выданные организатором 20 000 изображений нужно положить в `data/test/images/`.
`sample_submission.csv` задаёт идентификаторы и их порядок, а не истинные метки.

## Для повторения fine-tune

Сохранённые кропы и сплиты предпочтительнее новой выборки из H5: они сохраняют
точные исходные изображения завершённого эксперимента. После распаковки
ожидается следующая структура относительно корня репозитория:

```text
data/
  processed/line_crops/
    en/                       английские исходные PNG
    ru/                       русские исходные PNG
    metadata.csv              80 000 извлечённых кропов
    metadata_filtered.csv     71 155 кропов после геометрического фильтра
    train.csv                 60 520 исходных кропов
    validation.csv            10 635 исходных кропов
  raw/                        необязательно, только для повторения извлечения
    en/train/train_000.h5
    ru/train/train_000.h5
```

Это требования к расположению входов, а не проверенный список содержимого
ещё не загруженного ZIP. Если архив содержит дополнительную верхнюю папку,
перенесите `data/` в корень проекта. Парные 0°/180° варианты и manifests создаёт
`src/build_orientation_dataset.py`; отдельно хранить их в архиве не обязательно.

Синтетический источник — [NVIDIA OCR-Synthetic-Multilingual-v1](https://huggingface.co/datasets/nvidia/OCR-Synthetic-Multilingual-v1),
CC BY 4.0, NVIDIA / Ryan Chesler. Это синтетические страницы с текстом, не
датасет реальных вывесок. Изменения автора: извлечение строк, геометрический
фильтр, групповой split и повороты. Raw H5 нужны только для стадий download/extract,
но не для обучения на готовых кропах и не для inference.

## Перед передачей ссылки проверяющему

- Загрузить архив и добавить сюда его точное имя, размер и SHA256.
- Включить доступ «Все, у кого есть ссылка → Читатель» для папки и архива.
- Проверить ссылку в браузере без входа в свой Google-аккаунт.
- Проверить дерево каталогов после распаковки; не включать окружение `.venv`,
  личные ключи, токены и серверные конфигурации.

На Windows SHA256 можно получить так:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'путь_к_архиву.zip'
```
